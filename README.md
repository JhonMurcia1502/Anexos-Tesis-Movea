# Anexos Metodológicos - Proyecto MOVEA

**Trabajo de Grado:** Aproximación física del comportamiento del isotopólogo HDO como trazador de masas de aire en la atmósfera tropical.

Este repositorio contiene el código fuente para el procesamiento, filtrado estricto y renderizado cinemático de datos satelitales (misión Aura, instrumento MLS). Actúa como anexo de transparencia metodológica y reproducibilidad computacional para la investigación.

### Instrucciones de Reproducibilidad
Para ejecutar este análisis de forma interactiva:
1. Abra el archivo `Repositorio_MLS.ipynb` utilizando el entorno de Google Colab.
2. Ejecute la primera celda de configuración. El sistema configurará el entorno de trabajo y descargará automáticamente los datos vectorizados masivos (`.parquet`) desde el repositorio de Zenodo.
3. Ejecute las celdas de renderizado de manera secuencial.
